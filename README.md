## インストール

1. [Modrinth App公式サイト](https://modrinth.com/app) からアプリを導入する。
2. このリポジトリから `VDESK_WORLD_MODPACK_v1.0.1.mrpack` をダウンロードする。
3. Modrinth Appの **Create an Instance → Import Instance（Import from file）** などから読み込む。UIの表示はアプリ版によって異なる。
4. **Unknown file warning** が出たら、これはModrinth内で公開・審査されていないパックであると理解し、[内容一覧](MODS.md) と [安全性について](SECURITY.md) を確認する。判断できない場合は **Don't install** を選ぶ。
5. 独立した専用Minecraftプロファイルを起動する。既存の `mods` フォルダへ直接上書きしない。
6. 運営から個別に案内される**テストサーバーの接続先**へ接続する。アカウントの許可登録が必要です。

## ゲーム内のクリック式ガイド

テストサーバー入室時にチャットへ操作ガイドが自動表示されます。**Tキーでチャットを開き、青・緑の【ボタン】部分をクリック**すると、専用の移動・動作確認コマンドが実行されます（OP権限不要）。

案内は ①杖・剣を受取る → ②石・土・木を壊す → ③NPC37種類の右クリック・会話 → ④3秒間のカメラ演出 → ⑤VキーによるVCマイク確認 の順番です。

- チャットを閉じた、表示が流れてしまった場合は /trigger vdesk_guide set 1 で何度でも再表示できます。
- NPCエリアとメインエリアの往復も、チャット内のボタンから行えます。
- エリアへ移動した直後にはその場所での操作手順を表示します。
- 初回入室・再ログインに合わせた自動案内を設定しています。再ログイン時の表示は引き続き実機で確認中です。
- この変更は **テストサーバー側のみ**です。配布済みのMODパックは変更していません。

## HUB経由のテストサーバーへの入り方

**VDESK WORLDの通常HUBと、Fabric MODテストサーバーは同じVelocityネットワークに接続する構成です。**

1. Modrinth AppでこのMODパックを導入したプロファイルを起動。
2. 運営から案内されたVDESK WORLDの**通常HUB／Proxyのアドレス**に接続。
3. HUBのゲーム内チャットで **/server modtest** を入力するとMODテストサーバーへ切り替わります。
4. テスト終了後は **/server hub** で通常HUBへ戻れます。/server 単体でVelocityのサーバー一覧も表示できます。

注意事項：

- **HUB側にMODを入れる必要はありません。** FabricのMODパックを導入したクライアントなら、MODなしの通常HUBを経由してMODテストサーバーを目指せる構成です。
- **MODがないクライアントではMODテストに参加できません。** ProxyはMODを自動配布しません。
- テストサーバーはホワイトリスト制です。配信者には運営が事前にアカウント登録します。
- この接続経路はVelocityの設定登録と両サーバーの起動まで確認済みですが、**HUB → MODテストのプレイヤー実移動は2026-10-18に管理者の実機で成功を確認済み**です。もし切り替え時に拒否されたら運営へ状況を知らせてください。
- Velocity転送対応としてサーバー専用のFabricProxy-Lite 2.11.0を追加しています。**配布パックv1.0.1は1つの原因MODを除外して28MODに更新されています。**

## HUB内のNPC作成からMODテストへ（管理者向け）

HUBで運営用NPCを作成する場合、VDESK管理ツールの「NPC作成」画面に **「MODテストサーバー用NPCを作成」**（エンダーアイコン）を追加しました。権限を持つ運営者のみが利用できます。

この項目で作ったCitizens NPCはクリック時のVelocity接続先がmodtestになります。通常HUB、DISC、EVENTなど既存のNPC作成先は残しています。

**HUB側はMOD不要。** 接続する配信者にはFabric v1.0.1のMODパックと、テストサーバー側のホワイトリスト登録が必要です。NPC作成ボタンの実クリック・作成後の移動は現時点では実機の最終確認待ちです。

### 1サーバー内の3つのテストエリア

1つのMODテストサーバー、1つのワールドの中で、メイン・NPC会話展示・NPC戦闘を別の場所に分けています。

- **メインエリア:** 魔法・戦闘・カメラ・VC。新規プレイヤーのスポーン地点。
- **NPC専用エリア:** 会話と見た目を確認できる展示NPC（37体）と、入口の会話テストNPC（1体）。
- **NPC戦闘専用エリア:** 赤い名前の専用NPCを剣で倒す区画。落下防止の壁と床があり、倒したNPCは約4秒後に自動で再出現します。会話展示エリアとは別です。
- **移動:** チャットの案内ボタン、または /trigger vdesk_npczone set 1 と /trigger vdesk_home set 1 で移動できます。
- **会話:** 入口の「VDESK 会話テストNPC」を右クリックし、挨拶と「次のセリフへ」の選択肢を確認します。奥の展示NPC37体にも簡単な挨拶と「次のセリフへ」の選択肢を設定しています。

エリアの変更はサーバー側のみです。配布済みMODパックを入れ直す必要はありません。

### 常時暗視と建築テスト

- **暗視:** サーバーが全プレイヤーへ無期限の暗視効果を自動付与し、解除されても再適用します。参加者自身のコマンド・OP権限は不要です。
- **クリエイティブ:** テスト環境の標準ゲームモードはCreativeです。スポーン保護は無効に設定済みです。
- **ブロック破壊:** メインエリアの床上、X=-98から-96、Z=5 に石・土・木材の破壊確認用ブロックを置きました。壊れない場合はスクリーンショットとブロック位置を運営へ連絡してください。
- **NPC:** 37種類それぞれに日本語の名前と2段階の会話を設定し、起動時とNPCエリア移動時に会話設定を再適用します。

※サーバーの権限設定・クライアント実操作のすべてについて動作保証するものではありません。クライアントでのブロック破壊については引き続き実機確認中です。


マイクの入力テストは1人で可能ですが、相手に声が届くかどうかは2人以上で確認してください。テストワールドは本番ストーリーの再現ではありません。

**現時点の確認範囲:** クライアントからの接続、VCサーバー認証、2エリア間の移動、Easy NPCの会話メニュー起動、NPC37種類のサーバー会話データ、全員への暗視効果をサーバー上で確認しました。MOD全28件の個別機能、会話の選択肢遷移を含むすべての画面表示、外部からの接続、2人での実通話はまだ保証できません。

### NPC攻撃・討伐テスト（専用NPC）

会話確認のNPC38体は保護されています。別途、**攻撃・討伐を試す専用の赤い名前のNPC**をメインエリアに追加しました。

1. チャットの「NPCの攻撃・討伐テストはこちら」または /trigger vdesk_npckill set 1 を選びます。
2. 専用NPCを剣で攻撃します。一般のNPC展示とは異なり、無敵解除・プレイヤー攻撃許可を設定済みです。
3. 倒すと約4秒で自動的に再出現します。すぐに試す場合は「攻撃NPCを再出現」をクリックします。

サーバーコマンドによるダメージの反映（体力20→17）までは確認済みですが、実プレイヤーによる討伐は未確認です。
